# Cybersecurity-Program for WellNest Inc.

## Objective
With the advent of COVID-19, the healthcare sector has seen significant growth, especially in Telehealth services. With the increased demand for remote healthcare solutions, organizations like WellNest, which currently provides virtual consultations, remote patient monitoring, and mental health services are expanding rapidly. The organization has approximately 1,000 employees, consisting of administrative and clinical staff and sub-contractors. The organization operates in a hybrid technical environment with both cloud-based and legacy systems. 	However, as the healthcare industry becomes more digitalized, it becomes more vulnerable to cybersecurity threats. Patient health data is one of the most valuable targets for cybercriminals and making sure that robust cybersecurity measures are implemented is essential for the protection of sensitive patient information and organizations' operations. 

Project: Cyber Care, aims to design and implement a comprehensive cybersecurity program for WellNest and their telehealth product (also called WellNest) to mitigate risks, ensure compliance with healthcare regulations, and provide secure services for patients. The program will be designed around the NIST Cybersecurity Framework (CSF), to address key components of the organization’s cybersecurity posture. The core program will focus on governance, risk management, technical solutions, employee training, and incident response while ensuring compliance with regulations such as HIPAA and FDA guidelines for medical devices. 

WellNest is an integrated product that includes secure video conferencing, secure messaging for patient-provider communication, an Electronic Health Record (EHR) system, and various patient monitoring tools. Cloud security will be a core focus, as the organization leverages hybrid infrastructure with AWS to host critical patient data and run healthcare services. The program will touch upon incorporating secure software development lifecycle (SDLC) practices to ensure application security is integrated from the initial design phase to deployment. 

A selection of appropriate security tools will be addressed such as endpoint detection and response (EDR) systems, security information and event management (SIEM), and encryption technologies. An important component of the project is the development of a comprehensive incident response plan (IRP) and disaster recovery strategy. Employee awareness is another cornerstone of the cybersecurity program. The project will aim to outline a cybersecurity training and awareness program for all employees. Covering topics such as phishing prevention, secure data handling, and responding to cyber incidents. Lastly, the development of an executive-level reporting framework will ensure that leadership have actionable insights into the organization’s cybersecurity posture. 

Integrating risk management principles, employee training, ensuring data integrity and regulatory compliance, project Cyber Care will provide WellNest with a comprehensive, scalable cybersecurity program that prepares the organization for future threats. 


### Skills Learned

- Advanced understanding of SIEM concepts and practical application.
- Development of critical thinking and problem-solving skills in cybersecurity.

### Tools Used

- Security Information and Event Management (SIEM) system for log ingestion and analysis.
